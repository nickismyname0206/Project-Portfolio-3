## 📌 Project Overview

This portfolio showcases my involvement in the **logistics planning, vendor coordination, remote event monitoring, crisis management, team coordination and cost negotiation** for a private Ramadan gathering involving approximately **50 guests**, including family members, close associates and VIP guests.

I was appointed as the:

### **Logistics & Vendor Coordinator**

Although I was not physically stationed at the event venue, I managed the event logistics remotely through continuous communication with vendors and the on-site support team.

The project required strong coordination, time management, negotiation and problem-solving skills to ensure that operational challenges did not negatively affect the guest experience.
